# TANEM — шаблон стоматологии

В репозитории находятся действующие версии сайта для компьютера и телефона: главный экран, информационные карточки, переключаемые услуги, блок о клинике, частые запросы и форма. Перенесены компоненты, стили, мобильное меню, закреплённая панель, анимации появления и движущаяся лента. Палитра — голубой и синий.

Это шаблон с нейтральными полями. ФИО, контакты, адрес, опыт, количество пациентов, лицензия и цены не заполнены. Иллюстрации демонстрационные; перед выпуском их заменяют собственными фотографиями клиники.

## Запуск и проверка

Node.js 24 рекомендуется.

```sh
npm ci
npm run dev
npm run check
npm test
npm run build
npm start
```

`npm run dev` открывает Next.js на `http://localhost:3000`. `npm run build` создаёт статический сайт в `out/`. `npm start` раздаёт эту сборку и сохранённый API заявок; сначала выполните сборку. Для GitHub Pages используется `npm run build:pages` с путём текущего репозитория.

## Заполнение

Единый файл данных — `public/site-data.js`. После изменения данных нужна новая сборка.

- `clinic`: название, контакты, адрес, юридические сведения, тексты и изображения.
- `template`: подписи, заголовки, факты, информационные карточки, частые запросы и изображения ленты.
- `services`: названия направлений, описания, перечень услуг, цены и состав стоимости. Сейчас две карточки-заготовки; можно добавлять направления.
- `doctors`, `documents`, `consentVersion`: подтверждённые сведения для проверки готовности реального сайта. В этом перенесённом макете отдельного блока врачей и каталога документов нет; при запуске клиники их требуется вывести отдельной задачей.

Пустые контакты показываются как поля шаблона. Значения «—» означают незаполненные сведения, а не медицинские показатели.

В режиме `demo` форма проверяет телефон и согласие, не делает сетевой запрос и прямо сообщает, что заявка не отправлена. Имя необязательно. Диагнозы и комментарии не собираются. Реальный приём заявки подтверждается только после ответа серверного API; при ошибке поля сохраняются.

Исходные личные материалы, старые скрытые версии интерфейса и чужая конфигурация размещения в этот шаблон не входят.
