# TANEM — цифровой офис стоматологии

Шаблон для небольшой стоматологической клиники с несколькими врачами. Пересобран по визуалу и композиции актуального офиса Дмитрия Рихальского: крупная типографика, портретный главный экран, подробные услуги, редакционный блок о клинике и тёмная простая форма. Палитра — голубой и синий.

Визуальный и структурный образец: [цифровой офис Дмитрия Рихальского](https://github.com/ichAEY/-dm_rihalsky), изучен commit `06a3c326140a849d587c8796a6ae6a540980a71c`. Код, фотографии, личные сведения и медицинские обещания специалиста не перенесены.

## Запуск

Нужен Node.js 22.16+; рекомендуем Node.js 24. Зависимостей npm нет.

```sh
npm start
```

Откройте `http://127.0.0.1:3000`. В режиме `demo` форма проверяет данные и честно сообщает, что заявка в клинику не отправлена. Введённые в образец номера не сохраняются и не доставляются.

```sh
npm run check
npm test
npm run build
```

Статическая версия появляется в `dist/`. Ссылки на ресурсы относительные: шаблон работает и в подпапке GitHub Pages.

## Что собрано

- Адаптивный главный экран с иллюстративным портретом, крупным заголовком и двумя действиями.
- Стоматологические направления: вкладки переключают подробную панель с услугами, составом и ценами. На телефоне выбор направления располагается над панелью; доступны стрелки, Home и End.
- Несколько врачей, отдельные сведения об образовании, квалификации, аккредитации и часах приёма.
- О клинике, первый визит, организационные вопросы, реальные отзывы со ссылками.
- Форма: обязательный телефон, необязательное имя, отдельное согласие, ошибки рядом с полями.
- Контакты, маршрут, подключение существующего сервиса записи.
- Пациентские документы с поиском, версия с увеличенным текстом, клавиатурная навигация.
- Серверный приём заявок: SQLite, защита от дублей, очередь уведомлений и повторная доставка.
- Подключение Яндекс Метрики и анонимного события успешной заявки после настройки владельцем.

## Заполнение клиники

Контент находится в `public/site-data.js`. Не публикуйте вымышленные имена врачей, цены, стаж, лицензии, отзывы или фотографии.

1. Заполните название, юридические сведения, телефон, адрес, часы и вход.
2. Оставьте только фактически оказываемые направления; внесите полный прайс, единицы расчёта и состав стоимости.
3. Внесите реальные ФИО, фотографии, образование, квалификацию, аккредитацию и часы приёма врачей.
4. Добавьте документы клиники, отдельный текст согласия и его версию.
5. Замените все демонстрационные иллюстрации фотографиями клиники и её специалистов.
6. Настройте получателя заявок и условия хранения на сервере.
7. Переключите `mode` на `live`, проверьте сборку и выполните контрольную заявку на свой тестовый номер.

Конфигурация `live` проверяется до запуска. Пустые документы, цены и карточки врачей, а также демонстрационная иллюстрация блокируют выпуск. Проверка подтверждает заполнение полей, а не достоверность сведений или юридическую полноту документов.

Для реальных заявок нужен сервер. GitHub Pages и другая статическая раздача подходят для просмотра образца, но не запускают Node API.
