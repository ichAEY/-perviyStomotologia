# Правила шаблона

Перед изменениями прочитайте README.md, docs/PLAN.md и docs/DEPLOYMENT.md.

- Изменяйте только этот репозиторий. Сохраните перенесённый дизайн, композицию, адаптивность и голубую/синюю палитру.
- Последняя задача пользователя — полностью перенести действующий интерфейс в чистый шаблон. Не подменяйте перенос новой интерпретацией дизайна.
- Контент обеих версий находится в public/site-data.js; после правок пересоберите сайт.
- Не придумывайте медицинские факты, цены, ФИО, стаж, лицензии и отзывы.
- Не переносите чужие личные тексты, фотографии, ссылки, формы, счётчики или конфигурацию размещения.
- Заявка — телефон, необязательное имя и отдельное согласие. Не добавляйте диагнозы и анкеты.
- В demo не отправляйте и не сохраняйте данные. Успех в live показывайте только после подтверждения сервера; при ошибке сохраняйте поля.
- Не выдавайте этот макет за готовый к запуску сайт клиники.
- После изменений запускайте npm run check, npm test и npm run build.
- Проверяйте главный экран, форму и переключение услуг на телефонах, планшетах и компьютерах, когда доступен браузерный просмотр.
