# Правила шаблона

Перед изменениями прочитайте README.md, docs/PLAN.md и docs/DEPLOYMENT.md.

- Это самостоятельный стоматологический шаблон TANEM. Изменяйте только этот репозиторий.
- Сохраните голубую/синюю палитру. Последняя правка пользователя — дорогой визуал и композиция по актуальному офису Дмитрия; обновлённая структура описана в docs/PLAN.md.
- Содержимое клиники меняется в public/site-data.js.
- Не придумывайте медицинские факты, цены, ФИО, стаж, лицензии и отзывы.
- Структуру образца Дмитрия можно использовать; его медицинские тексты и личные данные не копировать.
- Услуги — направления стоматологии, а не салонные категории и длительность процедур.
- Заявка — телефон, необязательное имя, отдельное согласие. Не добавляйте диагнозы и анкеты в базовую форму.
- Успех в live показывается только после подтверждения сервера. Данные при ошибке остаются в форме.
- В demo не создавайте впечатление реальной записи.
- Новые автоматизации и коммерческие модули не входят в этот выпуск.
- После изменений запускайте npm run check, npm test и npm run build.
- Проверяйте главный экран, форму и подробные вкладки услуг на телефонах, планшетах, компьютерах и при увеличении текста.
