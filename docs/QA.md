# Проверка перенесённого шаблона

Перенесены активные версии для компьютера и телефона, включая их стили, анимации, меню, закреплённую панель и движущиеся ленты. Старые скрытые деревья интерфейса не включены.

Проверка конфигурации охватывает обе версии, якоря, уникальные идентификаторы, существование всех изображений, синтаксис JavaScript и типы TypeScript. Сборки для корня домена и подпапки GitHub Pages проверяются отдельно.

Тесты API проверяют телефон, согласие, незаполненную конфигурацию live, сохранение заявки до подтверждения, повторную и одновременную отправку, чужой origin, ограничения частоты и размера, отсутствие сохранения в demo, очередь уведомлений, SQLite и закрытые файлы. Отдельно проверяется CSP с хешами встроенных скриптов статической страницы.

Текстовые файлы, имена ресурсов и итоговая сборка проверены на оставшиеся личные имена, контакты, исходный адрес, фотографии и медицинские сведения конкретного специалиста. Иллюстрации взяты из собственного стоматологического образца; личные фотографии исходного сайта не перенесены.

Браузерный визуальный просмотр в этом окружении не выполнялся: навык управления браузером отсутствует. Автоматические проверки не подтверждают внешний вид на реальных устройствах. Перед выпуском конкретной клиники нужен просмотр телефона, планшета и компьютера, заполнение реальных данных и отдельное расширение разделов врачей и документов.

Локальные check, 11/11 тестов и обе сборки прошли. В GitHub Actions проверка и сборка шаблона также прошли. Публикация Pages остановилась на настройке хостинга: Pages в репозитории не включён (404 на Get Pages site). Поэтому публикация оставлена отдельным ручным workflow после включения Pages.
