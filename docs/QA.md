# Проверка версии

Проверены синтаксис JavaScript, конфигурация, уникальность HTML id, якоря, статические ресурсы и сборка.

Автоматические сценарии:

- вставка российских номеров в нескольких форматах;
- обязательное согласие и необязательное имя;
- запрет запуска с незаполненной конфигурацией клиники;
- сохранение до ответа об успехе;
- повторная и одновременная отправка одной заявки;
- отсутствие согласия, устаревшая версия согласия, неверный телефон, чужой origin;
- ограничение частоты, размер запроса и поле для защиты от ботов;
- отсутствие реальной отправки в demo;
- ошибка уведомления, повторная доставка и идентификатор для защиты от дублей;
- сохранность SQLite после повторного открытия и удаление по сроку;
- отсутствие доступа к закрытым файлам.

Адаптивная CSS-вёрстка содержит варианты для узких телефонов, телефонов, планшетов, ноутбуков и широких экранов. Главный экран растёт по содержимому, на телефоне текст не наложен на изображение; на узком экране кнопки идут в колонку. Услуги используют вкладки с ролями tablist/tab/tabpanel, одним элементом в Tab-порядке и переключением стрелками/Home/End. Код клавиатурного поведения проверен статически; взаимодействие в браузере не проверено. Уменьшенная анимация учитывает системную настройку.

Браузерный визуальный просмотр и интерактивные проверки в реальном браузере в текущем окружении не выполнялись: доступный навык управления браузером отсутствует. Полная визуальная проверка разных размеров и устройств остаётся обязательной перед выпуском сайта конкретной клиники. Автоматические тесты API не подтверждают внешний вид страницы.

Пересборка 11 октября 2026 года: заменены структура и CSS, созданы портретная и интерьерная иллюстрации, дополнена проверка конфигурации live против выпуска с демонстрационными изображениями. В статическом тесте проверяется возврат основного HTML, а не конкретный рекламный заголовок.

Итог локальных проверок этой пересборки: 11/11 автоматических тестов прошли; check и build успешны; проверены подписи полей, отдельное неотмеченное согласие, структура разделов, ресурсы, роли вкладок и основные цветовые пары (контраст от 5,51:1). Эти проверки не являются браузерной проверкой адаптивности.
