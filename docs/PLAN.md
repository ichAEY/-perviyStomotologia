# Текущая задача — перенос в шаблон

Полностью перенести активный дизайн и структуру исходного сайта в самостоятельный репозиторий стоматологии. Удалить персональные сведения, контактные идентификаторы, фотографии, медицинские утверждения и метаданные конкретного специалиста. Не менять дизайн произвольно.

## Состав

Компьютер: шапка → главный экран с крупным заголовком и иллюстрацией → информационные карточки → переключаемые услуги → о клинике → частые запросы → контакты и форма.

Телефон: компактная шапка и меню → главный экран → движущаяся лента → иллюстрация и информационные карточки → услуги → о клинике → лента запросов → контакты → тёмная форма. Закреплённая панель и переключение цвета браузера сохранены.

Обе версии используют единый файл `public/site-data.js`. Незаполненные показатели остаются «—», цены и контакты пусты. Нет вымышленных отзывов, имён и медицинских квалификаций.

## Граница текущего выпуска

Это перенесённый макет-шаблон, а не завершённый сайт конкретной клиники. Дополнительные разделы врачей, полного каталога документов, отзывы, карта и аналитика требуют отдельного согласованного расширения. API заявок и его существующие проверки сохранены; публичный образец работает в demo.
